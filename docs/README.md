# Team8 객체지향 프로그래밍 프로젝트

### 문서 구성

* **전체 구조:** 클래스 간 관계 및 의존성
* **클래스별 설명:** 멤버 변수, 주요 메서드, 역할
* **실행 흐름:** 프로그램 시작부터 주요 기능 실행까지의 과정
* **통합 이슈:** 코드 통합 과정에서 발생한 문제와 해결 방법

### 문서 작성 원칙

1. 각 팀원은 자신이 작성한 클래스의 역할을 설명합니다.
2. 다른 클래스에서 호출하는 주요 메서드의 사용법을 작성합니다.
3. 클래스 간 의존성과 주의사항을 기록합니다.
4. 코드가 변경되면 관련 문서도 수정합니다.
